## 1. 一句话定位

多层多视图 SSL 的**显式算子复合 + 端点一致性**表述，配一台可证伪的
**闭合测量仪器**：路径支持的依赖证书三元组 (C^dir, C^comp, Δ^CK)。
在深度对齐的嵌套随机视图层级上，比较端点直测算子与逐边条件算子的
有序全矩阵复合，闭合亏差 Δ^CK 经 Weyl 界给出证书谱 s^cert。

三条方法学红线（区别于既往做法）：必须中心化、每层共享坐标系、
全矩阵复合（**禁 σ-乘积**）。

**Wave 0**：六个冻结反例 + Gaussian-Hermite 解析链全部按预期行为，
仪器在解析可控的设定下经过验证。

## 3. 仪器故事：本周核心进展（figures/fig_instrument.png, fig_c100.png）

这是我认为最该在会上讨论的一节，因为它同时包含一个负面结果和一个
正面结果，而两者是自洽的。

### 3.1 CIFAR-10：仪器分辨率不足（负面，如实报告）

- 把 Stage-B 校准从 2500 加倍到 5000（合池等同 held-out 的 val）：
  所有 defect 统一下降约 0.04 —— **Thm 1 的 ε_n 噪声地板被实证并量化**。
- **但显式（V7, 0.209）与加性（V3, 0.199）在任何 ridge 下都不分离**，
  加性甚至略低。打平不是校准样本量的伪影。
- **星型树负控同样是零结果**：打破 Markov 嵌套后 probe 84.1 /
  defect 0.434，对比嵌套 85.0 ± 0.7 / 0.370 ± 0.050，z = 1.28，落在
  种子散布内。已核实 `hparams.yaml` 记录 `mode: parallel`，配置确实
  生效，是真实零结果而非无操作。（已补 2 个种子，在跑。）
- 正面的一半：**仪器确实能分离"为闭合训练过"（≈0.20）与"没训练过"
  的 flat 行（≈0.43）**，只是分不开显式与隐式两种训练方式。

### 3.2 CIFAR-100：分辨力出现（正面）

| 行 | 精度 | 亏差 | 每种子 |
|---|---|---|---|
| flat M-view | 61.46 ± 0.36 | 0.485 | 0.480, 0.496, 0.480 |
| **V7 full method** | 55.89 ± 0.32 | **0.375** | 0.377, 0.372, 0.378 |
| additive M-view | 48.52 ± 0.55 | 0.398 | 0.409, 0.389, 0.396 |

**显式 < 加性 < flat，三组种子零重叠**，且 V7 精度同时高出 additive
7.4pt。这是第一个显式闭合训练在仪器上与加性分离的设定。

**连贯叙事**：CIFAR-10 任务太易、表示太饱和，仪器分辨率不足；
CIFAR-100 上结构信号才浮出。星型负控已搬到 CIFAR-100 重做（在跑）。

## 4. 仪器交付物三支柱

### 4.1 通道谱学（figures/fig_spectroscopy.png，表 7）

扫某一条边的增强参数，**只有该边的算子范数移动**：edge1 的
min_scale 从 0.2 扫到 0.95，edge1 范数单调 10.62 → 11.48，而 edge0
钉死在 4.16。边定位归因成立，且已在 v8 冠军 checkpoint 上复现。

edge0 的 flip 扫描是**零响应的空通道**——backbone 对水平翻转不变
（CIFAR 类别镜像对称），仪器如实报告"这条通道没有信息"，没有
编造响应。这本身是仪器可信度的证据。

### 4.2 探测深度画像（figures/fig_depth.png，表 6）

stage 级组合质量保留率区分预训练与随机初始化：预训练网深层保留
0.88-0.93 且最佳探测层在 stage 4；随机初始化单调衰减到 0.661，
最佳探测层退到 stage 2。resnet18/50/152 与 CIFAR-100 均已覆盖。

### 4.3 Plug-in 研究（figures/fig_beta_sweep.png, fig_plugin.png，表 3）

闭合正则挂到外部 SSL 基座（backbone 只多见到闭合正则这一项）：

| Barlow Twins | 精度 | 亏差 |
|---|---|---|
| base (n=3) | 84.99 ± 0.38 | 0.537 |
| **+plugin β=16 (n=1)** | **85.12** | **0.241** |
| +plugin β=32 (n=3) | 83.10 ± 0.09 | 0.293 |
| +plugin β=48 (n=1) | 84.69 | 0.232 |

**β=16 上闭合亏差砍掉约 55%，精度不降**（同种子对比：base seed1
85.30 → β=16 seed1 85.12，−0.18pt）。这是 plug-in 最强的一句话。

诚实附注：β 在 16/32/48 上**非单调**（β=32 反而最差），β=16/48 目前
n=1，已升 3 种子在跑。VICReg 无论 β 都要付 7-10pt 代价（base 87.0 →
β=16 79.9）；FroSSL 的基座在统一配方下不稳定（32%），已排除出主分析。

## 6. 建议讨论的三个问题

1. **仪器分辨率**：CIFAR-10 的打平是根本限制还是可去偏？我倾向后者
   —— V7 被直接优化的 C^dir 可能有选择膨胀、分母偏置，需要 Thm 2
   的交叉拟合 ε_n 去偏来验证。这是下一步最有价值的理论-实验联动。
2. **论文定位**：主张应落在"仪器 + 表述"而非"显式闭合训练涨点"。
   CIFAR-100 的分离和 plug-in 的免费 defect 下降是最硬的两块。
3. **规模**：CIFAR-100 上信号才出现，是否值得上 ImageNet 子集/STL-10
   来确认趋势随任务难度增强。
