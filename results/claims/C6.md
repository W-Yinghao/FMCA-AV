# C6 conclusion card

Claim ID: C6
Question: Under which assumptions can local Markov spectra be composed across lag?
Primary estimand: direct-versus-composed spectrum error and Chapman–Kolmogorov residual
Pre-registered positive/negative criterion: machine-precision exact composition for reversible/normal chains, a detectable nonnormal counterexample, and complete OU/double-/multi-well boundary sweeps
Code version label / config / data split / seeds: file-based harness artifacts and frozen state-machine manifests; see linked source tables.
Compute budget: exact run-level GPU/CPU duration, encoded views and hardware are retained in runs/, results/index and E10 assets.
Main result with 95% CI: normal/reversible max median spectrum MAE=1.818e-15 (largest 95% CI half-width=3.048e-16); nonnormal median spectrum MAE=0.01041 (largest 95% CI half-width=0.002688); continuous dynamics=['double_well', 'multi_well', 'ornstein_uhlenbeck']
Numerical stability and failed runs: retained in results/index/failure_atlas.csv and the raw experiment tables.
Decision: PASS
Narrowest supported statement: One-step spectral powers compose exactly only in the reported reversible/normal regimes; continuous finite-sample errors and nonnormal failures define the boundary.
Unsupported stronger statement: A general singular-value power law for arbitrary nonnormal Markov dynamics is not supported.
Required manuscript change: use only the narrowest supported statement and disclose failed/negative controls.
Next experiment (if any): none selected from test performance; any future work must be declared exploratory.
