# Gate 1 附录 2：白化算子训练目标（APPENDUM，v1 结果已见，披露）

**日期：** 2026-08-17
**触发：** gate1_20260816_v1 全部 21 单元完成但**全部塌缩**（7 变体 probe 13–30%，正常 flat SSL 应 ~85%）。训练曲线显示 loss 跑到 −2×10¹⁹：score 与 whitening 罚项均为特征尺度的四次方，其比值尺度不变 ⇒ 一旦某形态下 score 超过 γ·罚项，放大尺度即无界下降。梯度裁剪只减缓步长，不改方向。**v1 的全部数值已见并存档；本附录为实现更正，冻结的 E1/E2/E3 对比不变。**

## 根因归责

"原始中心化矩 + 软白化罚"是**实现者对冻结代数的误读**：冻结本体 §2.2 把所有算子定义在中心化白化坐标上（σ ≤ 1，score 有界），§5 的 γ 项是条件数正则而非白化的唯一机制。经典 FMCA（trace/log-det）正是在白化算子上有界的。责任在实现者（我）。

## 更正

1. 训练时所有算子改在**批白化特征**上计算：每层一个共享 Cholesky 白化 W_ℓ（可微、三角求解、近简并谱下梯度稳定；与 R^{-1/2} 差一个正交因子，所有报告量 gauge 不变）。score 项自然有界（≤ ~1 每模式）。
2. γ 项保留：raw 层矩的逐元素 (R−I)² 均值（条件数辅助）。
3. flat 行只含叶层项（避免共享罚项训练未使用的 projector 污染对照）。
4. 发散哨兵回调：|train/loss| > 50 即中止单元（有界目标下不应触发）。
5. 塌缩判据更正为 probe < 15%（熵型 eff-rank 对本仓库历史上 83% 正常模型也给 1.055，只作诊断不作判据）。
6. Stage-B/C 测量协议不变（对称 eigh 白化、冻结坐标）。

## 验证

74 个单元测试全绿，新增：score 尺度不变性（×1000 特征 score 不变）、任意尺度下 loss 下界（> −4）。
